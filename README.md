# Aim Dental — Practice Intelligence Demo

A client demonstration dashboard concept for Aim Dental Group's multi-clinic operations across Western Australia.

## Features
- **Executive Overview**: Daily appointments, chair utilisation, recall due, and revenue metrics with clinic filtering.
- **Appointment Trends**: Weekly chair activity distribution.
- **Clinic Directory**: Locations, contact details, and hours for Woodvale, Innaloo, Maddington, and Merredin clinics.
- **Clinical Services & Team**: Service catalog and practitioner directory.
- **Operations & AI**: Concept workflow agents for automated reception, recall scheduling, documentation, and reporting.

## Live Demo
Deployed on Vercel.
